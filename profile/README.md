## What we are

We publish what we build as we build it, including the parts that are not finished. Performance figures in our devlogs name the fixture they were measured on.

## Arventus: The Frontier Village

An open-world RPG built on base building and an adventurer guild. The player arrives at a frontier settlement as an unknown and chooses a livelihood — an ordinary trade, guild contracts, a caravan route, or the underworld.

Every path is a running economic loop rather than a quest chain. Standing with each faction is a second currency alongside coin. No path ends the game: remove the mayor and another faction fills the chair. Characters age and die, and a run continues through whoever inherits.

**Status:** in development. Next milestone is a playable demo. [Read the design note →](https://voxelwavestudio.com/pages/posts/frontier-village-pivot)

## How it is built

| | |
|---|---|
| **Engine** | Godot 4.7 |
| **Platform** | PC first, via Steam |
| **World** | Meadow Terrain — our own procedural terrain technology |
| **Simulation** | Deterministic agent decision chain, prototyped and measured outside the engine |

Meadow Terrain generates grassy slopes, exposed cliffs, carved rivers and matching collision from a shared-corner quad graph, with a streamed backend covering a 7,000 × 7,000 cell world. Rendering, collision and surface queries all read the same topology, so placement logic and the player see identical ground.

[How the world generation works →](https://voxelwavestudio.com/pages/posts/meadow-terrain-world-generation)
